# Cyber Challenge — Static GitHub Pages Build

This folder is a static HTML/CSS/JavaScript conversion of the latest Cyber Challenge build.

## Run locally
Open `index.html`, or serve this folder with any static HTTP server.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` / root.
4. Open the generated Pages URL.

## Included
- Arabic + English RTL/LTR
- 4 security domains
- Initial test, educational challenges, final test
- Existing visual identity and animations
- Correct/incorrect effects and short feedback
- XP, ranks, badges
- Before/After score
- Certificate page with a **single-page print layout**
- Certificate **PNG download** generated in the browser
- Country selection
- Local browser demo ranking

## Static limitations
There is no Node/Express/SQLite server in this build. Therefore live global rankings, protected server admin authentication, and server-side certificate verification cannot be truly global/server-secure on GitHub Pages. Ranking and certificate verification are local to the browser.
